# franzranz – Rekuperations-Singlespeed

E-Fahrrad ohne Ladebuchse: Energie kommt nur aus der Bremse (Rekuperation), abgerufen per Boost-Knopf beim Anfahren.

- `docs/konzept.md` – Urteil zur Machbarkeit, Optionen, Komponenten, Risiken, Vorversuch mit Abbruchkriterien
- `sim/energiebilanz.py` – Simulationsmodell und Grundauswertung (`cd sim && python3 energiebilanz.py`)
- `sim/anfahren.py` – Vergleich der Boost-Strategien beim Anfahren
- `sim/machbarkeit.py` – echte Frontmotoren, Superkondensator, Ampelabstand, Ausrollen, Alternativen
- `docs/sim-*.md` – aktuelle Ausgaben der drei Skripte
