# franzranz – Rekuperations-Singlespeed

E-Fahrrad ohne Ladebuchse: Energie kommt nur aus der Bremse (Rekuperation), abgerufen per Boost-Knopf.

- `docs/konzept.md` – Anforderungen, Entscheidungen, Komponenten-Shortlist, offene Punkte
- `sim/energiebilanz.py` – Energiebilanz auf einer synthetischen Stadtstrecke (`python3 sim/energiebilanz.py`)
- `docs/sim-ergebnis.md` – aktuelle Ausgabe der Simulation
